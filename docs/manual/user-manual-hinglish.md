# Safar English — User Manual (Hinglish)

Ye manual Safar English app/website ke student panel ke liye hai. Har screenshot asli app se liya gaya hai aur laal arrow batata hai ki kya karna hai.

---

## 1. Home page (Landing)

![Home page (Landing)](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u01-landing.png)

- Sabse pehle safarenglishka.vercel.app kholiye.
- Upar menu me Courses, Books aur Login ke link milenge.
- Padhai shuru karne ke liye upar right side Login par tap kijiye.

## 2. Login kaise karein

![Login kaise karein](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u02-login.png)

- Email Address box me apni email id likhiye.
- Password box me apna password daaliye (aankh icon se password dekh sakte hain).
- Sign In button dabaiye — seedha Dashboard khul jayega.
- Chaahein to 'Sign in with mobile OTP' se mobile par OTP lekar bhi login kar sakte hain.
- Password bhool gaye ho to 'Forgot password?' par tap kijiye.

## 3. Dashboard — aapka main page

![Dashboard — aapka main page](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u03-dashboard.png)

- Login ke baad sabse pehle yahi page khulta hai.
- Upar aapka chaalu batch dikhta hai, neeche offer/notice ka banner.
- 'Resume' dabate hi aap wahin se padhna shuru karenge jahan chhoda tha.
- Neeche shortcuts: All Classes, All Tests, My Doubts, Library, Notices, Performance.
- Left upar menu (☰) se saare pages khulte hain.

## 4. My Courses — aapke course

![My Courses — aapke course](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u04-my-courses.png)

- Yahan sirf wahi course dikhte hain jinme aap enroll hain.
- Course card par tap karke chapter aur lecture ki list khulti hai.
- Har course ke aage progress bar batata hai kitna poora hua.

## 5. All Courses — naya course lena

![All Courses — naya course lena](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u05-courses.png)

- Yahan Safar English ke saare course/batch dikhte hain.
- Course kholkar syllabus, fees aur demo video dekh sakte hain.
- 'Enroll' dabane par payment screen khulti hai — UPI (PhonePe/GPay/Paytm), card ya netbanking chun sakte hain.
- Payment successful hote hi course My Courses me aa jata hai.

## 6. Books — kitaabein

![Books — kitaabein](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u06-books.png)

- Yahan batch se judi kitaabein aur notes milte hain.
- Kitab par tap karke andar PDF reader khulta hai.

## 7. Downloads — offline saamaan

![Downloads — offline saamaan](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u07-downloads.png)

- Download kiye hue notes/PDF yahan milte hain.
- Net na ho tab bhi ye files khul jaati hain.

## 8. Doubts — sawaal poochhna

![Doubts — sawaal poochhna](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u08-doubts.png)

- 'Ask a doubt' par tap kijiye.
- Sawaal type kijiye, chaahein to photo laga dijiye.
- Submit dabaiye — teacher ka jawab isi page par aayega.

## 9. Notices — soochnayein

![Notices — soochnayein](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u09-notices.png)

- Class time, chhutti, test ki jaankari yahan aati hai.
- Nayi soochna aane par upar ghanti (🔔) par laal nishan dikhta hai.

## 10. Community — baaki students se baat

![Community — baaki students se baat](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u10-community.png)

- Yahan batch ke doosre students ki post padh sakte hain.
- Apni baat likhkar post kar sakte hain — bhasha saaf-suthri rakhiye.

## 11. Reports — aapki pragati

![Reports — aapki pragati](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u11-reports.png)

- Test ke number, haaziri aur video dekhne ka hisaab yahan milta hai.
- Kamzor topic pehchaan kar wahin dobara mehnat kijiye.

## 12. Messages — teacher se sandesh

![Messages — teacher se sandesh](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u12-messages.png)

- Teacher/admin ke bheje sandesh yahan aate hain.
- Zaroori ho to jawab bhi de sakte hain.

## 13. Profile — apni jaankari

![Profile — apni jaankari](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u13-profile.png)

- Naam, class, mobile number yahan update kijiye.
- Badlaav ke baad Save zaroor dabaiye.
- Agar page khaali dikhe to Retry button dabaiye — data dobara load hoga.

## 14. Settings — setting aur logout

![Settings — setting aur logout](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/u14-settings.png)

- Notification chaalu/band yahin se hota hai.
- Bhasha aur theme bhi yahin badalti hai.
- Sabse neeche Logout button hai — kisi aur ke phone par padha ho to zaroor logout kijiye.

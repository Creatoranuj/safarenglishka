# Safar English — Admin Manual (Hinglish)

Ye manual Safar English ke admin panel ke liye hai. Har section ka screenshot asli admin login se liya gaya hai; students ki private jaankari jaan-boojhkar blur ki gayi hai.

---

## 1. Admin login

![Admin login](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a00-admin-login-dashboard.png)

- /login par admin email-password se login kijiye.
- Login ke baad pehle normal Dashboard khulta hai.
- Ab URL me /admin lagaiye ya menu se Admin kholiye.

## 2. Overview — ek nazar me poora hisaab

![Overview — ek nazar me poora hisaab](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a01-overview.png)

- Upar paanch card: Total Students, Total Revenue, Total Courses, Pending Payments, Active Sessions.
- Neeche shortcut card se seedha us section me ja sakte hain.
- Refresh dabane par aankde taaza ho jaate hain.

## 3. Batches — batch banana/chalana

![Batches — batch banana/chalana](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a02-batches.png)

- Naya batch banane ke liye 'Create/Add' dabaiye.
- Naam, class, fees aur avadhi bhariye.
- Batch me kaun-kaun student hain, wo yahin dikhta hai.

## 4. Courses — course banana aur badalna

![Courses — course banana aur badalna](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a03-courses.png)

- Course ka naam, keemat, class aur thumbnail yahan set hote hain.
- Purana course kholkar Edit se badlaav kijiye.
- Course chhupana ho to use Unpublish/Inactive kar dijiye.

## 5. Live — live class

![Live — live class](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a04-live.png)

- Nayi live class schedule kijiye — batch, date, time aur link bhariye.
- 'Go Live' se class shuru hoti hai, students ko notification chala jata hai.
- Class khatam hone par recording course me jod dijiye.

## 6. Payments — payment jaanchna

![Payments — payment jaanchna](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a05-payments.png)

- Pending Payments ki list yahan aati hai.
- UPI/card ka reference dekhkar Approve ya Reject kijiye.
- Approve karte hi student ka course apne aap khul jata hai.

## 7. Users — user aur role

![Users — user aur role](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a06-users.png)

- Sabhi registered user ki list, naam-email ke saath.
- Right side dropdown se role badlein: Student / Teacher / Admin.
- Search box se naam, email ya number se khoj sakte hain; Export se CSV nikalta hai.
- Savdhani: Admin role sirf bharosemand vyakti ko dein.

## 8. Teachers — shikshak

![Teachers — shikshak](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a07-teachers.png)

- Shikshak jodiye aur unhe batch saunpiye.
- Kis teacher ki kaun si class hai, yahin dikhta hai.

## 9. Library — notes/PDF

![Library — notes/PDF](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a08-library.png)

- PDF, notes aur kitaabein yahan upload kijiye.
- Har file ko sahi course/batch se jodiye, warna student ko nahi dikhegi.

## 10. Doubts — sawaalon ke jawab

![Doubts — sawaalon ke jawab](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a09-doubts.png)

- Students ke poochhe sawaal yahan jama hote hain.
- Sawaal kholkar jawab likhiye aur Send kijiye.
- Jawab milte hi student ke Doubts page par dikh jata hai.

## 11. Upload — lecture/content daalna

![Upload — lecture/content daalna](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a10-upload.png)

- Pehle course chuniye (jaise CG Lecturer Batch ya VIP Offline Batch 2027).
- Chapter chunkar video link ya PDF jodiye.
- Kram (order) sahi rakhiye taaki students ko silsilewaar dikhe.

## 12. Schedule — time-table

![Schedule — time-table](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a11-schedule.png)

- Hafte ka time-table yahan banaiye.
- Har slot me batch, vishay aur samay bhariye.
- Student ko yahi time-table uske dashboard par dikhta hai.

## 13. Enrollments — student ko course dena

![Enrollments — student ko course dena](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a12-enrollments.png)

- Student chuniye, phir course/batch chunkar Assign kijiye.
- Offline (cash) fees wale student ko yahin se access dijiye.
- Galat assignment ko Remove se hataya ja sakta hai.

## 14. Banners — dashboard ke banner

![Banners — dashboard ke banner](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a13-banners.png)

- Students ke dashboard par dikhne wale offer banner yahan bante hain.
- Image, title, button ka text aur link bhariye.
- Purana offer khatam ho to banner Inactive kar dijiye.

## 15. Landing — website ka home page

![Landing — website ka home page](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a14-landing.png)

- Public home page ka text, hero section aur section kram yahan badalta hai.
- Badlaav Save karne ke baad website par turant dikhta hai.

## 16. Reviews — students ki raay

![Reviews — students ki raay](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a18-reviews.png)

- Students ke diye review yahan aate hain.
- Achhe review ko Approve kijiye — wo website par dikhenge.
- Galat/spam review hata dijiye.

## 17. Social — social link

![Social — social link](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a19-social.png)

- YouTube, Telegram, WhatsApp ke link yahan update kijiye.
- Ye link website ke footer aur app me dikhte hain.

## 18. AI Chatbot control

![AI Chatbot control](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a15-chatbot.png)

- Chatbot ke jawab, FAQ aur knowledge-base yahan se set hote hain.
- Agar AI band ho to student ko FAQ se jawab milta rehta hai.
- 'AI abhi busy hai' jaisa message dikhe to AI key ki jaanch karaiye.

## 19. Students — student list

![Students — student list](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a16-students.png)

- Sabhi students ki list, batch aur sthiti ke saath.
- Kisi student par tap karke uski profile aur progress dekhiye.

## 20. Attendance — haaziri

![Attendance — haaziri](https://raw.githubusercontent.com/Creatoranuj/safarenglishka/main/docs/manual/screenshots/a17-attendance.png)

- Date aur batch chunkar haaziri lagaiye.
- Report me har student ki upasthiti ka pratishat dikhta hai.
